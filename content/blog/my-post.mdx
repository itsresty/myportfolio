# Building My First Next.js Website

> Building a website isn't just about writing code. It's about turning an idea into something people can actually use.

## Introduction

Building a website from scratch is more than writing code. It is about understanding how different pieces work together to create something useful, accessible, and enjoyable to use.

For this project, I decided to build my portfolio using **Next.js**, **TypeScript**, and **Tailwind CSS**.

My goal was simple: create a professional portfolio where I can showcase my projects, skills, certifications, and experience while continuing to improve as a developer.

---

## Choosing the Right Tools

Choosing the right technology can make a huge difference when starting a project.

For this portfolio, I wanted a stack that was modern, flexible, and easy to maintain.

### Next.js

I chose **Next.js** because it provides a strong foundation for building modern React applications.

It gives me features such as:

- File-based routing
- Server components
- Static generation
- Image optimization
- Metadata management

### TypeScript

TypeScript helps make the codebase more predictable.

Instead of discovering certain mistakes only when the application runs, TypeScript can catch many problems during development.

### Tailwind CSS

For styling, I use **Tailwind CSS**.

It allows me to build layouts directly inside my components while keeping spacing, typography, colors, and responsive behavior consistent.
